# MEGN200-BuddE

Hello! This repository contains all the code used for MEGN 200 Team 64's BuddE Project.
Here is a quick run through of where to find everything:

**Transmission Code** - Found in the folder labeled "Tx"  
**Receiving Code** - Found in the folder labeled "Rx"  
 <br>

 >Note that the folder labeled .vscode contains only setup information, it is not relevant to our project.
>Similarly, the gitignore and the platformio.ini files found in the repo are used only for Arduino compatibility
>with VSCode and do not affect the function of our project.
